# 面试背诵笔记（项目版）

> 每个术语三行：💬 面试官怎么问 → ✅ 一句话答案（背这个）→ 🧠 记忆锚点
> 原则：先讲"是什么"，再讲"为什么重要"，最后给数字。答不出来就讲类比。

---

## 0. 开场 30 秒（背熟）

"我自研了一个 A 股多因子量化研究平台：800 只股票、6 年日频数据，
49 个因子，支持因子挖掘、机器学习合成、回测，以及最重要的——一套防自欺的
统计检验体系（正交化 + 过拟合检验）。用 Python + pandas + LightGBM + Streamlit 实现。"

---

## 1. 项目技术栈

💬 "Streamlit 是什么？"
✅ "一个 Python 写网页界面的框架——我写的量化分析代码，套上它就能变成可交互的网页工具，不用学前端。"
🧠 类比：给 Python 代码"套个壳"变成网站。

💬 "为什么用 pandas？"
✅ "它是 Python 处理表格数据的标准库，我的数据全是'日期 × 股票'的二维表，pandas 的透视表、滚动窗口操作正好对口。"
🧠 记忆点：你项目里所有因子都是 pandas 的 DataFrame。

---

## 2. 因子基础

💬 "什么是因子？"
✅ "因子就是一个可计算的打分指标，比如'20 日动量'（过去 20 天涨了多少）。每天给每只股票算一个值，用来预测未来收益。"
🧠 类比：因子 = 给股票打分的一种"算法"。

💬 "IC 是什么？"
✅ "IC（Information Coefficient）= 每天因子值和未来收益的相关性。IC 越高，说明这个因子越能预测未来涨跌。"
🧠 记忆点：IC = 预测力。你项目里 IC +0.055 算不错（A 股日频 0.02~0.05 已有效）。

💬 "IC_IR 是什么？"
✅ "IC 的平均值除以波动——看这个因子'稳不稳'，不只是强不强。"
🧠 记忆点：IC 看强度，IC_IR 看稳定性（类比：平均分 vs 成绩波动）。

💬 "换手率为什么重要？"
✅ "换手率 = 因子排名每天变动多大。排名天天变 → 调仓频繁 → 交易成本吃掉收益。所以高 IC 但高换手的因子不一定赚钱。"
🧠 记忆点：WQ 的 Fitness 公式就是惩罚高换手。

💬 "分层检验是什么？"
✅ "把股票按因子值从高到低分 5 组，看每组未来收益是否单调——最高组收益 > 最低组收益，因子才真有区分度。"
🧠 记忆点：不只是"相关"，要"分组单调"。

---

## 3. 防自欺三件套（项目最大亮点，必考）

💬 "正交化是什么？"
✅ "把因子里'抄作业'的部分剥掉：对行业、市值、风格做回归，取残差。残差还保留的预测力，才是因子自己的本事（独立 alpha）。"
🧠 类比：把"火锅店好吃"里的"川渝人带路 + 人均 500"因素去掉，看裸味道。
📌 你的实证：排行榜第一的因子 IC -0.08，剥离后变 +0.01（符号翻转）→ 纯暴露伪信号。

💬 "什么是暴露？"
✅ "因子悄悄押注了某些风格（比如'全是白酒股'），它的高收益其实是行业涨，不是因子本事。"
🧠 记忆点：暴露 = 蹭热点，alpha = 真本事。

💬 "DSR（Deflated Sharpe Ratio）是什么？"
✅ "把 Sharpe 比率按'试了多少次'打折。你挖了 244 个候选，最好的那个 Sharpe 很可能只是运气——DSR 就是惩罚这个运气成分。"
🧠 类比：抽 244 次彩票，最好的那张不等于你运气好——DSR 帮你算"打折后还剩多少"。

💬 "PBO（Probability of Backtest Overfitting）是什么？"
✅ "检验'你选出的最优因子，在样本外是不是反而垫底'的概率。PBO < 0.5 才算没过度拟合。"
🧠 记忆点：PBO 问的是"历史最优会不会是未来最差"。

💬 "MinTRL 是什么？"
✅ "Minimum Track Record Length：要多少年数据才能确认这个 Sharpe 不是运气。你项目里很多候选要 300+ 年——直接判死刑。"
🧠 记忆点：数据不够长 = 结论不可信。

💬 "n_trials 为什么重要？"
✅ "试的次数越多，'碰巧最好'的候选越强。所以过拟合检验必须知道你到底试了多少次（244）。"
🧠 记忆点：多重检验惩罚——试得多，标准就要严。

## 4. 机器学习部分

💬 "你的 ML 合成是怎么做的？"
✅ "把 49 个因子当特征，未来 20 天收益当目标，用 LightGBM（梯度提升树）学一个非线性组合——它自动找'什么因子组合 + 什么阈值'最预测。"
🧠 类比：单因子是"单个指标"，ML 是"把指标熔成合金"。

💬 "什么是 walk-forward？"
✅ "滚动训练：用 2023 年之前的数据训练，预测 2023 年之后；再把训练窗口往后推，重复。保证每步预测只用当时已知的数据。"
🧠 记忆点：walk-forward = 边走边学，只用过去预测未来。

💬 "无未来函数是什么？"
✅ "指'用到了当时不可能知道的信息'（比如用今天的收盘价预测昨天的决策）。我的设计从结构上保证：特征、目标、训练切分都不引用未来。"
🧠 记忆点：面试官问这个，重点答"结构性保证"，不是事后检查。

💬 "LightGBM 和线性模型区别？"
✅ "线性模型假设因子和收益是直线关系；LightGBM 能自动学非线性（比如'换手低但动量高才有信号'这种组合规则）。"
🧠 记忆点：非线性 + 自动找交互 = LightGBM 的价值。

💬 "ML 合成的结果为什么也要正交化？"
✅ "因为 ML 也会学到'市值大'这种暴露——我跑出来特征重要性第一名就是流通市值。所以 ML 因子同样过正交化，剥离后 IC 保留 51%。"
🧠 记忆点：ML 不是免检产品，同一套守门全都要过。

## 5. WorldQuant 表达式（方法论吸收）

💬 "WorldQuant 是什么？"
✅ "一个全球知名的量化因子挖掘平台/比赛（IQC）。它不给你代码，但公开了方法论：用'操作符组合'批量造因子。"
🧠 记忆点：我吸收的是**方法论**，不是抄代码。

💬 "表达式挖掘是什么？"
✅ "像搭积木：操作符（rank 截面排名、ts_mean 窗口均值、decay_linear 衰减加权…）套在字段上，自动组合出成百上千个候选因子，批量检验。"
🧠 类比：网格挖掘是"固定模板"，表达式挖掘是"自由组合"。

💬 "Fitness 是什么？"
✅ "WorldQuant 的综合打分：Sharpe × √(收益/换手)。把'赚得多 + 换手低'合成一个数，防止高换手刷分。"
🧠 记忆点：Fitness = 收益质量分，不是只看 IC。

💬 "相关性去重为什么重要？"
✅ "挖出来的候选经常是'同一个想法的变体'（高度相关）。去重后才知道你其实只有几个独立想法，也防止提交一堆重复因子。"
🧠 记忆点：去重 = 数清楚你有几个独立发现。

## 6. 工程与性能（技术面）

💬 "你的挖掘引擎怎么做到内存优化？"
✅ "流式处理：逐个候选'生成→检验→丢弃'，不把 244 个候选全放内存；峰值内存从 16GB 降到 1GB 以内。"
🧠 记忆点：流式 = 边算边扔。

💬 "正交化 15 小时怎么压到 3 分钟的？"
✅ "三招：① 逐日循环的 pandas 换成 numpy 批量矩阵运算；② 月频截面采样（20 个交易日取 1 个截面，435 个截面足够稳健）；③ 单线程 BLAS + 控制变量数组复用（内存降 20 倍）。"
🧠 记忆点：先量化瓶颈，再对症优化——面试官爱听这个思路。

💬 "测试怎么写的？"
✅ "94 个单元测试，全部用合成数据（零网络）：手算对拍操作符正确性、篡改未来数据验证无未来函数、构造相关序列验证去重逻辑。"
🧠 记忆点：测试 = 证明"我说对就是对"，不是嘴上说。

## 7. 诚实话术（被问到必答）

💬 "你的回测有没有幸存者偏差？"
✅ "有。我用的是现存成分股，历史回测会偏乐观。历史成分股回测是我规划的二期工作——这个局限我清楚，也在文档里标注了。"
🧠 记忆点：主动承认 + 给出方案 = 加分；被发现 = 扣分。

💬 "数据从哪来？"
✅ "新浪财经日线（前复权）+ 东财业绩报表，本地缓存 800 只 × 6 年。无 Level2 数据，大单资金流类因子做不了（这是二期）。"

💬 "这个项目最大的教训是什么？"
✅ "学会不信自己的结果：排行榜第一的因子（IC -0.08, t=-37 看着很惊艳）被我自己的正交化检验证伪——它只是行业/市值暴露。这个'证伪自己的发现'的过程，比任何技术点都重要。"
🧠 记忆点：这是你的杀手锏回答，背熟。

## 8. 一页速查（面试前 5 分钟扫）

| 术语 | 一句话 |
|---|---|
| 因子 | 给股票打分的指标（如 20 日动量） |
| IC | 因子和未来收益的相关性（预测力） |
| IC_IR | IC 的稳定性 |
| 换手率 | 排名变动频率（成本杀手） |
| 分层 | 分 5 组看收益是否单调 |
| 正交化 | 剥离行业/市值/风格，看独立 alpha |
| 暴露 | 蹭风格热点；alpha=真本事 |
| DSR | Sharpe 按试验次数打折 |
| PBO | 最优候选样本外垫底的概率 |
| MinTRL | 需要多少年数据才可信 |
| walk-forward | 只用过去数据滚动训练 |
| 无未来函数 | 结构性保证不用未来信息 |
| LightGBM | 非线性树模型，自动找组合规则 |
| Fitness | Sharpe×√(收益/换手)，WQ 综合分 |
| 表达式挖掘 | 操作符组合批量造因子（WQ 方法论） |
| 幸存者偏差 | 现存成分股回测偏乐观（已知局限） |
