# 组合风险约束设计

## 目标

在现有日频多头回测中加入可审计的组合构建约束：单股目标权重上限、行业目标权重上限和单次调仓成交额预算。约束应在订单生成前作用于目标组合，默认设置必须严格复现当前 TOP-N 等权行为；实际成交被涨跌停、停牌和参与率限制阻断时，系统必须把目标与实际执行区分开来。

## 方案比较与决策

1. **在成交后检查并提示超限。** 实现最少，但只能发现问题，不能降低模型目标暴露。
2. **确定性贪心目标构建 + 开盘前换手缩放。** 按因子得分从高到低分配权重，逐笔遵守单股和行业预算；再将当前开盘持仓向目标组合按换手预算比例靠近。无新依赖、结果可解释，适合当前等权 TOP-N 策略。
3. **二次规划/整数优化器。** 能加入跟踪误差、风格暴露和复杂交易成本，但需要求解器、可行性处理和额外的模型假设，超过本期范围。

采用方案 2。它不把贪心分配伪装成全局最优，只提供透明且可验证的硬上限。目标组合最多使用现有 `top_n` 个证券；当上限过严、行业候选不足或可交易性差时，未分配部分保留为现金，而不是突破风险边界。

## 约束模型

新增不可变 `PortfolioConstraints`：

- `max_stock_weight=1.0`：单只证券的目标权重上限；
- `max_industry_weight=1.0`：单个行业的目标权重上限；
- `max_rebalance_turnover=None`：关闭单次调仓成交额预算；启用后取值在 `(0, 2]`，表示开盘前组合净值的成交额上限（买卖名义金额之和）。

目标构建以信号日有效、成交量大于零的证券为候选。每个候选按以下值分配：

```text
min(1 / top_n, 单股剩余上限, 行业剩余上限, 未分配资金)
```

行业缺失的证券归入 `未知行业`，不能绕开行业约束。候选在得分降序中被处理，直到已选 `top_n` 只或没有可分配资金。因而默认值仍产生精确的 TOP-N 等权组合；绑定约束可能导致较少仓位或留存现金。

执行日以开盘价重估当前持仓。若目标股票权重为 `t`、当前股票权重为 `c`，计划成交额为 `sum(abs(t - c))`。当该值超过预算 `B` 时，执行目标改为：

```text
c + alpha * (t - c),  alpha = B / sum(abs(t - c))
```

这限制的是计划买卖总额而非年化换手。随后既有成交逻辑继续处理涨跌停、停牌、参与率和现金不足；因此实际成交额可能更低，且无法成交的旧仓位可能暂时仍高于新目标上限。

## 架构与审计

新增 `qfm.portfolio.constraints`，仅负责：

- 参数校验；
- 从信号、成交量和行业生成约束目标；
- 对开盘前当前权重和目标权重执行换手预算缩放。

它不读取 `DataPanel` 以外的数据、不下单、不写文件。回测内核调用它并为每次实际调仓写入一行 `constraint_history`：信号日、执行日、目标持仓数、目标投资比例、目标最大单股/行业权重、原始计划成交额、预算、缩放系数和预算是否绑定。

`BacktestResult` 末尾新增可选 `constraint_history`，不破坏现有构造调用。结果 `params` 记录规范化约束字典；研究运行载荷从此处归档该配置。策略页提供“组合风险约束”控件和“约束执行记录”展开表，显示持仓现金与换手预算的实际影响。

```text
信号日 score + volume + industry
  → constrained_target_weights
  → 次日开盘当前权重
  → apply_turnover_budget
  → 既有可成交性/容量/成本订单执行
  → BacktestResult.constraint_history + params
  → 策略页与研究项目 manifest
```

## 边界与错误处理

- `top_n`、上限和预算必须为有限数；单股/行业上限必须在 `(0, 1]`，预算为 `None` 或 `(0, 2]`。
- 没有足够有效候选时保留现有“空目标”规则；不强行用缺失价格或零成交量证券填仓。
- 行业数据缺失时使用 `未知行业`；行业上限仍然生效并在历史记录中可见。
- 本期不处理最小交易单位、指数跟踪、风格中性、借券、空头、个股禁买名单、point-in-time 成分股或全局最优配置。
- 目标约束和实际执行约束明确区分；对于不可卖旧仓位，页面显示的是目标状态和执行状态，不宣称实际仓位必然满足上限。

## 验收与测试

1. 默认约束产生与旧 `_target_weights` 相同的 TOP-N 等权目标。
2. 单股上限和行业上限在目标权重上严格成立；限制不足时目标总权重低于 1，残余为现金。
3. 未知行业不能绕过行业上限。
4. 换手预算缩放后计划成交额不超过预算，关闭预算时不改变目标。
5. 回测记录约束参数和每次调仓的审计行；既有成本、容量和可交易性逻辑仍生效。
6. 研究运行载荷包含约束配置；旧 `BacktestResult` 测试构造仍可用。
7. 新增测试零网络；全量 pytest、研究冒烟和隔离 Streamlit 页面验收通过。
