# 表达式挖掘 v1（WorldQuant 方法论吸收）

> 日期：2026-08-21 · 状态：已确认设计（AskUserQuestion），待实施
> 来源：WorldQuant BRAIN 表达式语言方法论（公开论文/比赛文档，独立实现，不抄码）

## 一、目标

把挖掘引擎从「49 因子 × 4 变换」（244 候选）升级为 **WQ 式操作符组合挖掘**：
`操作符(字段, 参数)` 表达式批量生成候选 → 现有三层守门（IC 检验 / 正交化 / 过拟合）。

## 二、已确认决策（用户）

| 项 | 决策 |

## 三、表达式 DSL（qfm/mining/expressions.py）

- 叶子 = 字段名（现有 49 因子 + 4 基础指标 + 新增技术指标）
- 操作符（全部只用 t 及之前数据，结构性无未来函数）：

| 操作符 | 语义 | 参数 |
|---|---|---|
| `rank` | 截面排名（横截面） | — |
| `ts_rank` | 时序排名（N 日窗口内） | N |
| `ts_mean` | 时序均值 | N |
| `ts_zscore` | 时序标准化 | N |
| `ts_std` | 时序标准差 | N |
| `decay_linear` | 线性衰减加权均值 | N |
| `delta` | N 日差分 | N |
| `abs` | 绝对值 | — |

- 候选名规范化：`{op}[_{N}]__{field}`，如 `ts_rank_10__turnover_20`、`rank__mom_20`
- 无未来函数：静态扫描器断言每个操作符输出 t 行只依赖 ≤t 的输入

## 四、技术指标字段扩充（qfm/mining/fields.py）

从 panel 纯 pandas 计算（无外部依赖），候选清单：
RSI(14)、BIAS(乖离率, 5/10)、量比(当日量/5日均量)、ATR(14)、
振幅扩展(high-low)、上涨/下跌量占比、金额动量变体、收盘位置(close 在 N 日区间位置) 等 10-15 个

## 五、引擎集成

- `generate_candidates_expr(panel, fields, ops)`：流式生成器（同 v2 思路，峰值≈单候选）
- 复用 `run_mining`（排行榜 + 试验矩阵落盘 → 支持 PBO）
- 排行榜新增两列：`Fitness`、`去重组`（相关性剪枝标注）

## 六、Fitness + 相关性去重（WQ 精华）

- `Fitness = Sharpe_ann × √(|ret_ann| / max(turnover, 0.125))`
  - Sharpe_ann / ret_ann：从试验矩阵月频收益序列计算
  - turnover：factor_report 换手率
- 相关性去重：取排行榜前 N（默认 50），用试验矩阵月频收益序列两两 Pearson 相关
  → 贪心：保留 |IC| 最高候选，剔除与其相关 >0.7 的，标记 `去重组=1/2/…`

## 七、验收

1. 表达式求值正确性：合成数据与手算对拍 + 无未来函数静态扫描通过
2. 字段计算正确性：合成数据对拍
3. 挖掘集成：合成面板跑通，排行榜含 Fitness/去重组列
4. 59 旧测试全绿 + 新增测试
5. 真实数据冒烟：index800 表达式挖掘（几百候选），输出排行榜 + 报告
6. 页面 Tab 可交互跑通
