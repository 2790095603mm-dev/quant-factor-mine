# 单因子检验与模拟一体化实施计划

用户已批准上一轮提出的一体化方案，本轮直接实现并验证。

目标：因子检验一次运行同时产生 IC 诊断、成本后 Sharpe、最大回撤、日均换手、Fitness、净值与分年表现。

设计选择：复用现有多头执行引擎；多空采用独立的研究模拟（50% 多头 / 50% 空头目标，不声称存在融券券源）。保持当前浅色紫色视觉，在参数下面优先展示绩效数字与净值，详细诊断放到页签中。默认月末调仓、Delay=1、Decay=0。Delay=1 表示收盘后信号下一交易日开盘成交。

## 实施与验收

- [ ] 统一绩效函数：日超额收益均值 / 日收益标准差 × sqrt(252)，支持无风险利率；分年收益接上上年末净值；测试手算收益序列。
- [ ] 增加 `qfm/simulation/engine.py`：校验设置、方向处理、历史窗口平滑、中性化、额外延迟、日期裁剪；接入现有多头回测；实际成交额 / 当日开盘交易前净资产形成日均换手；独立运行无费用对照。
- [ ] 增加 `qfm/simulation/long_short.py`：下一开盘执行、持仓盯市、交易费和融券费；测试同日禁止交易、方向、总敞口、费用与异常数据。
- [ ] 增加 `qfm/simulation/views.py`：参数表单、持久结果、待重跑提示、预测诊断、收益/回撤、分年、成交、HTML/CSV 下载及研究归档。保留多因子对比与正交化入口。
- [ ] 修复因子库跳转：使用回调在控件初始化前切换页面。
- [ ] 用合成数据验证信号无前瞻、反向因子、延迟、平滑、中性化、Fitness 算术与存档；用 Streamlit AppTest 验证按钮、结果保留与配置变更。
- [ ] 运行相关回归与真实缓存数据 smoke test，浏览器检查最终页面。

## 指标口径

Sharpe 使用成本后每日收益及可配置无风险利率。Fitness 是本地研究分数：Sharpe × sqrt(abs(252 × 平均日收益) / max(日均双边成交额占净值比例, 0.125))，不宣称等同 BRAIN。原表达式页的旧月频近似 Fitness 另作标识，不混用阈值。IC 检验未来 H 日收盘收益，模拟按下一开盘实际持仓计收益。分层统计不是可交易净值。

## 范围
